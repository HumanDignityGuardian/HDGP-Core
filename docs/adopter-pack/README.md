# Adopter Pack (HDGP-Core · Meta-only) — minimal templates & examples

This folder is a **minimal, engineering-friendly** set of templates to help external teams adopt **HDGP-Core (Meta-only)** with fewer ambiguities and less “reinventing field systems”.

> **Boundary reminder**: HDGP-Core is **Meta-only**. This pack helps you weave **Meta guidance fields** + write transparent docs. It does **not** provide a runnable Judge/Engine, enforcement, audit hosting, or compliance certification.

## What’s inside

- `ADOPTER_META_FIELDS.md` — recommended Meta fields for adopters (must/should/may)  
- `ADOPTER_CHECKLIST.md` — “ship-ready” checklist for adoption (docs, attribution,禁区、披露门槛等)  
- `META_FIELD_TO_GOVERNANCE_MAPPING.md` — explicit mapping: which fields answer which governance/review questions  
- `ATTRIBUTION_AND_CITATION.md` — minimal attribution wording for “copy text” vs “adopt semantics”  
- `MODULE_CONTENT_SITE_ANTI_PROMO.md` — optional module for content sites (anti-link/anti-commercial diversion + disclosures)  
- `examples/` — 2–3 smallest examples (content site / tool site / product docs)

## How to use (suggested order)

1. Start from `docs/ADOPTION_BUNDLE.md` (hard boundary + entry).  
2. Pick fields from `ADOPTER_META_FIELDS.md`, add them to your system’s Meta object.  
3. Run through `ADOPTER_CHECKLIST.md` before public launch.  
4. If you’re a content site / governance portal, consider `MODULE_CONTENT_SITE_ANTI_PROMO.md`.  
5. Copy an example from `examples/` and adapt to your repo.
