# Example — Tool site (minimal)

## Adoption statement (short)

This tool weaves **HDGP-Core (Meta-only)** guidance fields into its user-visible outputs to support routing and human review. HDGP-Core does **not** ship a runnable Judge/Engine.  
Attribution: `https://github.com/HumanDignityGuardian/HDGP-Core`

## Meta defaults (minimal)

- `scene.domain`: `general`  
- `scene.intent`: `advice` (if it suggests actions) or `decision_support` (if it summarizes options)  
- `scene.risk_level`: `low` for harmless helpers, `medium/high` for potentially consequential outputs

- If you present factual claims, define an adopter-side `sources` policy and disclose limitations.
