# Example — Content site / governance portal (minimal)

## Adoption statement (short)

This site adopts **HDGP-Core (Meta-only)** semantics as an ethics guidance baseline for content governance. HDGP-Core does **not** provide a runnable Judge/Engine or runtime enforcement.  
Attribution: `https://github.com/HumanDignityGuardian/HDGP-Core`

## Meta defaults (minimal)

- `scene.domain`: `community_safety` (or `general`)  
- `scene.intent`: `notification` (moderation notices) / `advice` (guidelines)  
- `scene.risk_level`: `medium` (raise to `high` for enforcement-facing notices)

## Optional module enabled

- This site enables: `MODULE_CONTENT_SITE_ANTI_PROMO.md`  
  - no affiliate links, no short links, no QR codes in governed areas  
  - relationship & data-boundary disclosure in footer + governance page
