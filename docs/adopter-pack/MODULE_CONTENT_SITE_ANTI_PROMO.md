# Optional module: content sites “anti-promo / anti-diversion” (adopter-side)

This module is **optional** and intended for adopters operating content sites (knowledge bases, governance portals, compliance-intake sites, documentation hubs).

It provides a minimal policy posture for:

- **anti external-link diversion** (avoid turning content into commercial traffic funnels)
- **anti short-link / QR diversion** (reduce covert marketing)
- **disclosure** (relationship and data boundary transparency)

> Scope note: this is an **adopter policy module**, not an HDGP-Core commitment and not runtime enforcement.

## 1) Anti-link / anti-diversion rules (recommended)

- **No affiliate / paid outbound links** in governed content areas.
- **No short links** (bit.ly style), **no QR codes** in governed content areas.
- **No disguised navigation** that primarily serves commercial diversion (e.g. “recommended reading” blocks that are ads in disguise).
- If outbound links are necessary for source citation:
  - link to primary sources (official docs, papers)  
  - label them as “source / reference” (not CTA)

## 2) Disclosure rules (recommended)

- **Relationship disclosure**: sponsors, partners, affiliate relationships, ownership ties.
- **Data boundary disclosure**: what data is collected, what is not, retention window, and whether third parties receive it.
- **Content boundary disclosure**: what the site does (governance, transparency, compliance intake) and what it does not do (marketing, sales, endorsement).

## 3) UI placement (practical)

- Put disclosure links in a stable footer and on “About / Governance” pages.
- Put a short “anti-promo stance” note near any area where users might expect promotions.
