# Attribution & citation (minimal guidance for adopters)

This document is **not legal advice**. It’s a minimal, practical wording guide so adopters avoid common mistakes in “credit and attribution”.

Always follow `LICENSE` in this repository.

## Case 1: You copied HDGP-Core text (verbatim excerpts)

Recommended minimum:

- Keep a clear attribution line near where you use the excerpt (or in a central `NOTICE` / `ADOPTION.md`), e.g.:
  - “This project excerpts materials from **HDGP-Core** (Apache-2.0): `https://github.com/HumanDignityGuardian/HDGP-Core`.”
- Link back to the repository (or GitHub Pages index) and preserve license notices as required.

## Case 2: You adopted the semantics but did NOT copy text

Recommended minimum:

- Add a “semantic attribution” line in your docs, e.g.:
  - “This project adopts the **Meta-only semantics** of **HDGP-Core** as an ethics guidance baseline (no Judge/Engine is implied): `https://github.com/HumanDignityGuardian/HDGP-Core`.”

## Avoid these common pitfalls

- Do **not** phrase attribution as “HDGP endorses us” or “certified by HDGP” unless you have a separate, explicit agreement.
- Do **not** imply HDGP-Core provides runtime enforcement, audit hosting, or compliance guarantees.
